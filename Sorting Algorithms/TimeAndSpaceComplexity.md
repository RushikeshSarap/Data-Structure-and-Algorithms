1. BubbleSort -> 
    Time: Best[O(n)], Avg[O(n^2)], Worst[O(n^2)]
    Space: O(1)

2. SelectionSort ->
    Time: Best[O(n^2)], Avg[O(n^2)], Worst[O(n^2)]
    Space: O(1)

3. InsertionSort ->
    Time: Best[O(n)], Avg[O(n^2)], Worst[O(n^2)]
    Space: O(1)

4. QuickSort ->
    Time: Best[O(nlogn)], Avg[O(nlogn)], Worst[O(n^2)]
    Space: O(logn)

5. MergeSort ->
    Time: Best[O(nlogn)], Avg[O(nlogn)], Worst[O(nlogn)]
    Space: O(n)
