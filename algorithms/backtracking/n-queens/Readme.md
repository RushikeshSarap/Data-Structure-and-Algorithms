# N-Queens

A backtracking algorithm that places N queens on an N×N chessboard so that no two queens attack each other.

## Complexity
* **Time Complexity:**
  * Best Case: O(n!)
  * Average Case: O(n!)
  * Worst Case: O(n!)
* **Space Complexity:** O(n)

## Features
* Backtracking: Yes
* Constraint-based: Yes
* Finds all valid placements (or one valid placement, depending on the implementation)
