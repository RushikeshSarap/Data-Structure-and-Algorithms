# Sum of Subsets

A backtracking algorithm used to find subsets of a given set whose elements sum to a target value.

## Complexity
* **Time Complexity:**
  * Best Case: O(2^n)
  * Average Case: O(2^n)
  * Worst Case: O(2^n)
* **Space Complexity:** O(n)

## Features
* Backtracking: Yes
* Goal-based search: Yes
* Useful for combinatorial decision problems and subset generation
