# 0/1 Knapsack

A classic dynamic programming problem that chooses a subset of items with weights and values to maximize total value without exceeding a capacity limit.

## Complexity
* **Time Complexity:**
  * Best Case: O(n * W)
  * Average Case: O(n * W)
  * Worst Case: O(n * W)
* **Space Complexity:** O(W)

## Features
* Dynamic Programming: Yes
* Optimal solution: Yes
* Each item can be chosen at most once
