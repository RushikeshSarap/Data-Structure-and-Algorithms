# Longest Common Subsequence

A dynamic programming algorithm that finds the longest sequence of characters common to two strings, preserving order but not necessarily contiguity.

## Complexity
* **Time Complexity:**
  * Best Case: O(m * n)
  * Average Case: O(m * n)
  * Worst Case: O(m * n)
* **Space Complexity:** O(m * n)

## Features
* Dynamic Programming: Yes
* Optimal substructure: Yes
* Commonly used in diff tools, text comparison, and bioinformatics
