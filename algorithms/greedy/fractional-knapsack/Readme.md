# Fractional Knapsack

A greedy algorithm that selects items by value-to-weight ratio to maximize total value, allowing fractions of items to be taken.

## Complexity
* **Time Complexity:**
  * Best Case: O(n log n)
  * Average Case: O(n log n)
  * Worst Case: O(n log n)
* **Space Complexity:** O(1)

## Features
* Greedy: Yes
* Fractional choice allowed: Yes
* Faster than 0/1 knapsack for continuous item selection
