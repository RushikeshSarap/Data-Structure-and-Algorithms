# Binary Search

A fast searching algorithm for sorted arrays that repeatedly divides the search interval in half.

## Complexity
* **Time Complexity:**
  * Best Case: O(1)
  * Average Case: O(log n)
  * Worst Case: O(log n)
* **Space Complexity:** O(1)

## Features
* Divide-and-conquer: Yes
* Works only on sorted data
* Much faster than linear search for large arrays
