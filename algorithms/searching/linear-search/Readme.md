# Linear Search

A simple searching algorithm that checks each element in order until the target is found or the list ends.

## Complexity
* **Time Complexity:**
  * Best Case: O(1)
  * Average Case: O(n)
  * Worst Case: O(n)
* **Space Complexity:** O(1)

## Features
* Simple to implement: Yes
* Works on unsorted data: Yes
* Good for small lists or one-time lookups
