# Insertion Sort

An incremental sorting algorithm that builds the final sorted array one item at a time by inserting each element into its correct position.

## Complexity
* **Time Complexity:**
  * Best Case: O(n)
  * Average Case: O(n²)
  * Worst Case: O(n²)
* **Space Complexity:** O(1)

## Features
* Stable: Yes
* In-place: Yes
