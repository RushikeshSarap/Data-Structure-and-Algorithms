# Merge Sort

A Divide and Conquer algorithm that splits an array in half, recursively sorts them, and merges the sorted halves.

## Complexity
* **Time Complexity:** 
  * Best Case: O(n log n)
  * Average Case: O(n log n)
  * Worst Case: O(n log n)
* **Space Complexity:** O(n) (Auxiliary space for merging)

## Features
* Stable: Yes
* In-place: No
