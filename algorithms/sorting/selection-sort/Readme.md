# Selection Sort

A comparison-based sorting algorithm that divides the array into a sorted and unsorted region, repeatedly selecting the smallest element from the unsorted region and moving it into the sorted region.

## Complexity
* **Time Complexity:**
  * Best Case: O(n²)
  * Average Case: O(n²)
  * Worst Case: O(n²)
* **Space Complexity:** O(1)

## Features
* Stable: No
* In-place: Yes
